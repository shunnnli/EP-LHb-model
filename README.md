# EP-LHb-model
 Network model of EP-LHb circuit

Implements a RNN-DQN model that simulates PID varient or normal Q learning in a mouse operant conditioning task. PID varient is adapted from [Bedaywi et al., 2024](https://arxiv.org/html/2407.08803v2).

1. Operant conditioning gym: OperantGym.py
2. Run Operant-PID.py to train a single agent.
3. Run Operant-Batch.py to train multiple agents.
